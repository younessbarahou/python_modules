# python_modules
A collection of python exercices with solutions from the (42 Common Core) that gives you a deep dive into python concepts.

<h1> General Rules </h1>
<ul>
<i><li><b>Type Hints Are required (python module >= 1)</b></li>
<li><b>Syntax Should Follow Flake8 Styling</b></li>
<li><b>Docstrings are Optional</b></li>
<li><b>Code Should Adapt Python Best Practices</b></li>
<li><b>Crashes Are forbidden</b></li>
<li><b>Leaks Are forbidden</b></li>
<li><b>Classes names -> Pascal case</b></li>
<li><b>objects_names -> Snake case</b></li>
</ul></i>
